# New Morning: Catastrophe Pack

Public Packwiz manifests and files for New Morning: Catastrophe.

## Channels

- `staging/` — alpha builds for developers and designated testers
- `stable/` — promoted builds for the broader testing group (coming later)

Minecraft mods and resource files referenced by Packwiz are downloaded from their official project sources. The small `nmc_*` compatibility mods are maintained specifically for this modpack.
